# Notepad-tkinter

A simple yet feature-rich notepad built using Python's Tkinter library. This lightweight text editor supports file operations, dark mode, font customization, live word count, and find/replace functionality.

🚀 Features

✅ New/Open/Save Files
Easily create, open, and save .txt files.

🌗 Dark Mode
Toggle between light and dark themes for comfortable reading and writing.

🔍 Find and Replace
Search for any word or phrase and replace it with just one click.

🔡 Change Font Size
Customize the font size to suit your preference.

🧮 Live Word & Character Count
Always know how much content you've written, updated in real-time.

📦 Requirements

Python 3.x

Tkinter (Usually comes pre-installed with Python)

▶️ How to Run

Make sure Python is installed on your system.

Save the script as notepad.py.

Run it using the command:

python notepad.py

📁 File Menu Options

New: Clear the current text area to create a new document.

Open: Load an existing .txt file.

Save: Save your current work to a file.

Exit: Close the application.

✏️ Edit Menu Options

Find and Replace: Open a dialog to search and replace text.

Change Font Size: Set a custom font size for better readability.

👁️ View Menu Options

Toggle Dark Mode: Switch between light and dark themes.
